## My process

### Built with

- Semantic HTML5 markup
- CSS custom properties (Variables)
- Flexbox for column layout and centering
- Mobile-first workflow

### What I learned

In this project, I learned how to:

- Structure a clean card layout using semantic HTML tags (`main`, `button`, `h1`, `p`).
- Use CSS Flexbox (`display: flex; flex-direction: column; gap: 12px;`) to manage clean vertical spacing down the card.
- Use `align-self: flex-start` to keep the category badge tucked into the corner without stretching across the card.
- Create an exact offset retro box shadow using `box-shadow: 8px 8px 0px 0px #000;`.

### AI Collaboration

Used AI as an interactive assistant to:

- Troubleshoot box-stretching issues and align the card.
- Verify semantic HTML tags (`<h1>`, `<button>`, `<p>`) for better accessibility.
